# 👑 プリンセス・ルーティン・クエスト (Princess Routine Quest)

子供が進んで朝晩の準備を楽しくコンプリートできる、ゲーミフィケーション型ルーティンタスク管理Webアプリです。

## ✨ 特徴
- 📱 **タブレット左右2分割モード**: 兄弟姉妹が喧嘩せず、同時にそれぞれのペースでタスクを進められます。
- ⚡ **オート・ステップアップ誘導**: 1つのタスクが終わると次のタスクが金色にパルス発光し、連続集中をキープ。
- 🚨 **親用『まほうのあつまれタイマー！』**: テレビに夢中なお子さんを10秒全画面アラートで引き戻します。
- 🎁 **まほうガチャ ＆ コレクションずかん**: 全タスク完了でガチャが解禁！全16種類以上のアイテムを収集可能。
- ⚙️ **個人専用タスク設定**: おくすりなどの個人タスク・共通タスクの追加・並び替えが自由自在。
- 🌐 **完全スタンドアロン & PWA対応**: サーバー不要（LocalStorage保存）、通信費0円、プライバシー安全。

## 🚀 使い方
1. `run_app.bat` をダブルクリックするか、`index.html` をブラウザで直接開きます。
2. GitHub Pages / Cloudflare Pages にデプロイすれば、スマホやタブレットからどこでもアクセス＆ホーム画面追加が可能です。
